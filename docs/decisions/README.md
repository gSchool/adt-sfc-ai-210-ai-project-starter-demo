# docs/decisions/

Decisions that outlive a single task.

A task's own reasoning closes out in its file in `tasks/`. This directory is for choices
that govern the project from then on: a convention adopted, a tool chosen, a boundary set,
an approach rejected for a reason worth remembering.

Use `templates/decision.md`. Name files so they sort: `0001-short-description.md`.
Link the important ones from `PROJECT.md` under Standing decisions.

**The value is the alternative that lost.** The choice itself is visible in the repository;
the reasoning is not.
