# logs/

What was actually run.

When a result turns out wrong three weeks later, the question is always the same — what did
it read, what was it asked, what came back — and the result alone cannot answer it.

A minimum entry: when, which task, which sources, what was asked, what came back, what was
decided. One file per run or one appended log; either is fine.

**This is the thinnest part of this starter, deliberately.** Practices for recording and
repeating runs come later. The directory exists so there is somewhere obvious to put it in
the meantime.
