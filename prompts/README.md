# prompts/

**Deliberately empty.**

Prompts that get reused belong here, versioned, with a note of what changed between
versions and why.

A prompt that worked once is a lucky result. A prompt someone else can run on the same
inputs and get a comparable result is a process. The difference is written down.

That practice comes later. **The directory exists now so adopting it means filling a slot
rather than reorganizing.**

Until then: if you catch yourself pasting the same prompt a third time, put it here even
without the structure. The structure can come later. The lost prompt cannot come back.
