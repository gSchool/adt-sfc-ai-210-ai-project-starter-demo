# Sources

What this project depends on, who owns it, and how current it is.

**Fill this in once and keep it honest as the project goes.** A missing owner or a date you
cannot establish is not a gap in this file — it is a finding about the source.

"The team" is not an owner. A person is an owner.

| File or system | What it is | Data or content | Owner (a person) | Last current | Notes |
|---|---|---|---|---|---|
| | | | | | |

---

**Data or content** — structured fields with enforced values are *data*: if they are wrong,
logic breaks. Free text is *content*: if it is wrong or stale, judgment breaks. Most real
records are both, and the content half is usually where the risk is.

**Last current** — when the source was last known good, not when you copied it here.

**If an owner is unknown**, three questions are worth more than the blank: who would you ask
to find out, roughly how long would that take, and what work is not blocked by not knowing?
