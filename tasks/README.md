# tasks/

One file per task. Copy `templates/task.md` and name it so it sorts:
`0001-weekly-summary.md`.

A task file is the brief going in and the record coming out. Start it before you work,
close it when the task ends.

**Keep them.** A directory of closed tasks is the most useful thing in this repository six
months from now — it is what tells the next person what has been tried, what worked, and
what was deliberately not done.

If a task file is getting long, that usually means it is more than one task.
