# templates/

| Template | Who fills it | When |
|---|---|---|
| `task.md` | **The agent**, before it starts work | Every task |
| `decision.md` | Either | When a choice outlives the task that prompted it |
| `source-check.md` | Either | When you do not trust an input |
| `readiness-check.md` | Either | When results keep coming out weak and you suspect the inputs |

**`task.md` is the one that runs every time**, and the agent writes it, not you. The other
three are instruments you reach for when something is wrong.

These are shapes, not forms. Change them to fit the work. The one thing worth keeping is
that every field can be honestly left as *unknown* — a template nobody can complete
honestly gets completed dishonestly.
